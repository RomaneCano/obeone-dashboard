# O.BeOne != CannotBe

Dashboard de l'équipe 2 (ISIS Castres, analyse critique du projet BeONE). Question guide : comment relier un cas humain à un aliment ou à un élevage sans exposer le patient ni l'exploitant ?

Pour ajouter une entrée, modifier un fichier de `data/` (`sources.csv`, `conformite.csv`, `beone.csv`) puis pousser sur `main`. Une GitHub Action lance `build.py` et republie la page.
Test local : `python3 build.py` puis ouvrir `docs/index.html`.
